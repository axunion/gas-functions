LINE Messaging API

sendToLine セットアップガイド

LINE Messaging API のプッシュメッセージでグループ等にテキストを送信するための準備手順です。

1. LINE 公式アカウントと Messaging API チャネルの準備

2024年9月4日以降、LINE Developers Console から Messaging API チャネルを直接作成することはできません。先に LINE 公式アカウントを作成し、そこから Messaging API を有効化します。

  1. LINE Official Account Manager で LINE 公式アカウントを作成（2025年6月25日以降、新規作成にはビジネスマネージャーとの接続が必須）
  2. LINE Official Account Manager の「設定」→「Messaging API」から Messaging API を有効化
  3. LINE Developers Console にログインし、作成された Messaging API チャネルを開く
  4. チャネルの「Messaging API」タブで チャネルアクセストークン（長期） を発行
  5. LINE Official Account Manager の「設定」→「アカウント設定」→「機能の利用」で「グループ・複数人トークへの参加を許可する」を有効化
注意: Messaging API 有効化時のプロバイダー選択は、後から変更も連携解除もできません。また、グループ参加を許可していない状態でボットをグループに招待すると自動退出します。

2. グループ ID の取得方法（Webhook 経由）

  1. LINE Developers Console でチャネルの「Messaging API」タブを開く
  2. Webhook URL を設定する（例: GAS の Web アプリ URL）
  3. Webhook の利用をオンにする
  4. LINE 公式アカウント（ボット）を対象のグループに招待する
  5. 招待時に届くイベントの source.groupId から ID を取得・保存する

GAS 側で Webhook を受け取る例:

function doPost(e) {
  const events = JSON.parse(e.postData.contents).events;
  for (const event of events) {
    if (event.source.type === "group") {
      Logger.log("Group ID: " + event.source.groupId);
    }
  }
  return ContentService.createTextOutput("OK");
}

3. 料金プランとメッセージ通数

プラン月額（税別）無料メッセージ数 / 月
コミュニケーションプラン0円200通
ライトプラン5,000円5,000通
スタンダードプラン15,000円30,000通（追加 3円/通〜）

通数は「送信リクエスト数 × 送信対象の人数」でカウントされます。1 リクエスト内の吹き出し（メッセージオブジェクト）数は関係ありません。

送信例カウント
10人のグループに 1回送信10通
5人のグループに吹き出し3つを 1リクエストで送信5通
40人のグループに 15回送信600通（無料枠超過）
応答メッセージ（reply）0通（無料）

ブロック中のユーザーなど、実際に届かない相手はカウントされません。

4. GAS での使用例

function notifyLine() {
  sendToLine({
    channelAccessToken: "YOUR_CHANNEL_ACCESS_TOKEN",
    targetId: "YOUR_GROUP_ID",
    text: "タスクが完了しました",
  });
}
Slack API

sendToSlack セットアップガイド

Slack の chat.postMessage API でチャンネルにメッセージを送信するための準備手順です。

1. Slack アプリの作成

  1. Slack API: Your Apps を開き、Create New App をクリック
  2. From scratch を選択し、アプリ名を入力して対象のワークスペースを選択
  3. サイドバーの OAuth & Permissions を開く

2. Bot Token Scopes の設定

スコープ用途
chat:writeメッセージ投稿に必須。送信だけなら他のスコープは不要

OAuth & Permissions → Scopes → Bot Token Scopes で追加します。

3. ワークスペースへのインストールとトークン取得

  1. OAuth & Permissions 上部の Install to Workspace をクリックして承認
  2. Bot User OAuth Token（xoxb-...）をコピー — これが token パラメータになる

4. チャンネル ID の取得

  1. Slack で対象チャンネルを右クリック
  2. チャンネル詳細を表示 を選択
  3. 詳細パネル最下部の チャンネル ID（例: C1234567890）をコピー
注意: 先にボットをチャンネルに招待しておくこと（/invite @ボット名）。招待していないと API が channel_not_found を返します。

5. GAS での使用例

function notifySlack() {
  sendToSlack({
    token: "xoxb-YOUR-BOT-TOKEN",
    channel: "C1234567890",
    text: "タスクが完了しました",
  });
}
