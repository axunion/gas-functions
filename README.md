# GAS Functions

TypeScript utility functions for Google Apps Script.

## Usage

Copy the required function files from `src/` to your GAS project.

## Development

### Requirements

- Node.js
- pnpm

### Setup

```bash
pnpm install
```

### Scripts

```bash
# Build
pnpm build

# Lint & Format
pnpm check
pnpm check:write

# Test
pnpm test
```
